# 定盘（出生时辰校准）设计说明

> 2026-08-30 实现。核心思路由用户提出：用过往真实经历反推出生时辰。

## 一、为什么可行：时辰对紫微是全局性的

| 术数 | 时辰变化的影响 | 定盘区分度 |
|---|---|---|
| **紫微** | 命宫 = 寅起正月顺数生月、**逆数生时** → 时辰一变，**十二宫整体重排**，大限流年全变 | **高（主要依据）** |
| 八字 | 只是多换一个时柱 → 影响身强弱与喜用神，盘结构不变 | 低（辅助） |

## 二、关键设计：按「年龄段」问，不按「第几段大限」问

**踩过的坑**：12 个时辰的大限**宫名序列完全相同**（命宫→父母→福德→田宅→官禄…），
只是每段覆盖的年数不同（五行局决定步长：水二局 2 年/宫、木三局 3、金四局 4、土五局 5、火六局 6）。

所以按「第几段大限」提问区分度为 0；必须按**具体年龄**问——
同一个 22 岁，土五局走到官禄、火六局还在田宅、水二局已近尾声、木三局在迁移。**区分度就来自这里。**

## 三、算法

```
1. 生成候选：full 模式 12 个时辰；refine 模式取给定时辰 ±1（3 个）
2. 预计算：每候选 × 过去 N 年 × 6 主题的流年活跃度 + 大限时间轴
3. 选题（信息增益最大优先）：
   - 题型 A 大限主题（主）：「你 X–Y 岁这段时期，生活重心在哪个方面？」12 选 1
   - 题型 B 流年强信号（辅）：「某年某方面有过变动吗？」有/没有/记不清
4. 贝叶斯更新后验；后验 ≥0.55 或问满 5 题即停
```

**信息增益公式（曾写反，已修正）**：
- 大限题：`gain = H(主题分布) / log2(主题种类数)` —— 候选预测越分散，问了越有用
- 流年题：`gain = H(p) × 0.6` —— **熵本身即增益**；所有候选预测一致时（p=0 或 1）熵为 0，不得选

## 四、自测结果（务必正确解读）

```
完全命中: 14/15 (93%) | 平均提问 4.0 题   [src/rectify-benchmark.js]
```

**这是算法自洽性验证，不是真人准确率。**
模拟用户是「按真实时辰的盘作答 + 15% 记不清噪声」，它验证的是：
给定一致的经验输入，算法能否收敛到正确时辰。

**真人场景的额外误差源**（需实测校准）：
1. 用户对「生活重心在哪个方面」的主观理解可能与命理宫位含义不同
2. 真实经历本身是多线的（同时有事业与感情变化），单选会丢信息
3. 记忆偏差（哪年发生的）比 15% 噪声更大

**已知的失效场景**：年龄太小（可问区间不足）。
测试中两个低把握案例都是 2003/2004 年出生（仅 2 个可问区间），
后验仅 17% / 24% —— **系统会诚实标记 `level: 'low'` 并建议按「时辰未知」处理**，不强行给答案。

## 五、置信度分级

| 后验 | level | 处理 |
|---|---|---|
| ≥ 0.55 | high | 定盘收敛良好 |
| 0.40–0.55 | medium | 有一定把握，请结合实际判断 |
| < 0.40 | low | **未定出**，建议按「时辰未知」解读 |

## 六、诚实边界（对用户的明示）

前端固定提示：**「都不符合也没关系——这恰恰说明此盘与你的经历吻合度低，我们会据此下调结论的把握。」**

这是刻意设计，用于防止反向证实偏差——避免用户为了迁就系统而"脑补"自己的记忆。
